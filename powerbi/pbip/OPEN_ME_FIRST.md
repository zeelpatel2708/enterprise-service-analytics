# Ready-made Power BI projects

| File | Edition | Contains |
|---|---|---|
| `enterprise_service_analytics.pbip` | A – simulated | 10 tables, 11 relationships (closed-date one inactive), 86 measures in folders, KPI Selector, marked date table, dynamic RLS role, 5 empty named pages |
| `calgary_311_operations.pbip` | B – real Calgary | 6 model tables + 6 comparison tables, 7 relationships, 33 measures, 5 empty named pages |

Generated by `powerbi/build_pbip.py` from the CSV files and the `.dax` measure files, so they always match the pipeline.

## Open a project

1. Power BI Desktop → **File → Options and settings → Options → Preview features**. If you see **Power BI Project (.pbip) save option** and **Store semantic model using TMDL format**, tick both and restart Power BI. If they're not listed, they're already switched on.
2. **File → Open → Browse** → `powerbi\pbip\enterprise_service_analytics.pbip`.
3. The tables are empty until loaded: **Home → Refresh** (about 30 s for Edition A, a few minutes for Calgary).
4. **View → Themes → Browse for themes** → `powerbi\northline_theme.json`.
5. **File → Save**. It stays a project (a folder of text files, which works well with Git). For a single file, use **File → Save as → .pbix**.

**Moved the project folder?** Go to **Home → Transform data → Edit parameters** and set `ProjectFolder` to the folder that contains `README.md`. Or re-run:

```
python powerbi\build_pbip.py --project-folder "C:\your\path\enterprise-service-analytics"
```

## Quick check after Refresh

Put a **Card** on a page with `_Measures` → `01 Volume` → **Total Requests**. Edition A should show **75,909**. More expected values are in `POWER_BI_BUILD_GUIDE.md` §10.

## If Power BI refuses to open a project

Send the error message. As a fallback:

- Load the tables manually (`power_query.m`).
- Then paste everything else in one go: **TMDL view** (left toolbar) → paste `tmdl_scripts\<name>.tmdl` → **Apply**.
